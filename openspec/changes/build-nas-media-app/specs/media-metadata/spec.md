# media-metadata

媒体元数据管理。编辑音视频的名称、描述、标签，管理封面图片。

## ADDED Requirements

### Requirement: 编辑媒体元数据

用户 SHALL 能编辑媒体的名称（title）和描述（description）。编辑后立即生效，无需重新扫描。

#### Scenario: 修改媒体名称和描述

- **WHEN** 用户在媒体详情页修改名称和描述并保存
- **THEN** 系统更新数据库中的 title 和 description 字段
- **AND** 前端立即反映更新后的信息

#### Scenario: 名称留空时使用文件名

- **WHEN** 用户清空媒体名称
- **THEN** 系统自动回退为文件名（不含扩展名）作为默认名称

### Requirement: 标签管理

媒体 SHALL 支持添加和移除标签。标签支持自定义名称和颜色。用户可以从已有标签中选择，也可以创建新标签。

#### Scenario: 为媒体添加标签

- **WHEN** 用户在媒体详情页选择一个已有标签或创建新标签并添加
- **THEN** 该媒体与该标签建立关联，在浏览页可看到标签标记

#### Scenario: 为媒体移除标签

- **WHEN** 用户在媒体详情页移除一个已关联的标签
- **THEN** 该媒体与该标签的关联被删除，媒体不再显示该标签

#### Scenario: 创建新标签

- **WHEN** 用户在标签管理或媒体编辑中创建新标签
- **THEN** 系统保存标签（名称 + 颜色），可供其他媒体使用

#### Scenario: 标签颜色

- **WHEN** 创建标签时指定颜色或使用系统自动分配的颜色
- **THEN** 标签在前端以对应颜色显示

### Requirement: 自定义封面上传

用户 SHALL 能手动上传封面图片替换自动生成的封面。支持的图片格式为 JPG 和 PNG。

#### Scenario: 上传自定义封面

- **WHEN** 用户在媒体详情页上传一张 JPG/PNG 图片作为封面
- **THEN** 系统保存该图片，覆盖自动生成的封面，前端立即显示新封面

#### Scenario: 删除自定义封面

- **WHEN** 用户删除手动上传的封面
- **THEN** 系统回退为自动生成的封面（若存在），否则显示默认占位图

### Requirement: 自动封面生成

系统 SHALL 在扫描新视频时自动生成封面：取视频 10% 时长位置的一帧作为封面。若该帧为黑场（平均亮度 < 30/255），则回退到 30% 位置重新取帧。

#### Scenario: 正常视频生成封面

- **WHEN** 视频 10% 时长位置的帧平均亮度 ≥ 30/255
- **THEN** 系统使用该帧生成封面 JPEG 图片（宽度 480px，等比缩放）

#### Scenario: 黑场回退

- **WHEN** 视频 10% 时长位置的帧平均亮度 < 30/255
- **THEN** 系统回退到 30% 位置取帧。若仍为黑场，回退到 50% 位置

#### Scenario: 音频文件默认封面

- **WHEN** 系统为纯音频文件生成封面
- **THEN** 系统使用默认占位图（音乐图标 + 主题色背景）
